## Scope

This report tests whether the v0.6 scorer measures its declared typed and behavioral contract. It
does not establish that the synthetic convenience-retail environment predicts real deployment
performance. External validity, discriminating task design, long-horizon behavior, evaluator
validation, and empirical model comparison remain later roadmap gates.

## Trace checks

The trace validator checks contract version, root identity, unique ordered spans, parent linkage,
event type, success/error shape, evidence ID uniqueness, evidence lineage, result presence, and
payload hash integrity. The terminal event retains only the public structured decision and does not
request provider-private chain-of-thought. Common secret formats are minimized when tool arguments
and results are captured.

## Maintainer spot-check before merge

The PR reviewer should open at least one clean and one perturbed non-mock `.eval` trace and confirm:

- task prompt fields match the public construct registry;
- each claim-level support explanation agrees with the cited payload;
- expected and observed typed values match the generated world;
- required or prohibited actions agree with tool and ledger behavior;
- the terminal trace and parent lineage are complete;
- null metrics are displayed as inapplicable, not zero; and
- the composite arithmetic reproduces the scorer breakdown.

Record the reviewed run IDs in the PR or release checklist. Until that review and merge approval,
the implementation is a release candidate rather than a completed external validation study.
